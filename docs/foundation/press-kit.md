# Press Kit

Official Bitcoin Dev Kit brand assets for use in articles, presentations, and community projects. Both files are vector SVGs, so they scale to any size without losing quality.

[Download Press Kit (.zip)](../assets/press-kit/bdk-press-kit.zip){ .md-button .md-button--primary download="bdk-press-kit.zip" }

## Usage

You're free to use the logo and icon wherever you refer to Bitcoin Dev Kit: articles, talks, slide decks, websites, apps that use BDK, and community projects. No need to ask for permission.

The files ship in a dark color (`#13161F`), but feel free to recolor them to suit your design, for example white on a dark background or a color that matches your brand.
